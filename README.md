# 语音记账

做完一件事，拍下消费凭证、说一句「干了什么、花了多少」，就记好一笔账。
它是一个手机网页应用（PWA），添加到主屏幕后用起来和普通 App 一样，可以离线使用，数据只存在你自己的手机里。

## 怎么用

1. **开始一件事**：首页写上「接下来要做什么」（比如“拜访客户”），可以选一个预计时长，点「开始」。
2. **做完了**：点「✅ 做完了，记一笔」，会直接弹出记账页面，自动带上事项名称和用时。
   如果设了预计时长，到点会提醒你「做完了吗？」。
3. **记一笔**：
   - ① 点「📷 拍凭证」拍小票、付款截图等（可以多张）；
   - ② 点一下话筒说一句，比如“和客户吃午饭，花了一百二十八块”，再点一下结束；
   - 金额（128）和类别（餐饮）会自动识别填好，不对可以手动改；
   - 点「保存」。
4. **定时提醒**（设置页）：打开后，在你设定的时段里，一段时间没记账就提醒一次。
5. **账单 / 统计**：按月查看每一笔、按天汇总；统计里有每日支出、按类别、按事项（花了多少钱、多少时间）。
6. **导出**：设置页可以导出 CSV 表格（Excel 能打开），或导出包含照片和录音的完整备份，换手机时再导入。

### 语音识别能听懂的说法

| 说法 | 识别结果 |
| --- | --- |
| 花了一百二十八块 / 128元 / ¥128 | 128 |
| 二十八块五 / 28块5 | 28.5 |
| 三块五毛 / 五毛 | 3.5 / 0.5 |
| 打车20块，吃饭35块 | 55（自动相加） |
| 早饭8块午饭25块一共33块 | 33（以「一共」为准） |
| 加油花了300 | 300 |

类别根据关键词猜：吃饭/外卖/咖啡→餐饮，打车/地铁/加油→交通，超市/淘宝→购物，等等。

## 安装到手机

应用需要通过 **HTTPS** 打开（摄像头和麦克风的要求）。最简单的方式是用 GitHub Pages：

1. 在 GitHub 仓库 **Settings → Pages** 里，Source 选 “Deploy from a branch”，选这个分支和 `/ (root)`，保存。
2. 过一两分钟会得到一个网址，例如 `https://<你的用户名>.github.io/Claude-Code-Time-and-Money-manager/`。
3. 手机打开这个网址：
   - **iPhone（Safari）**：分享按钮 → 「添加到主屏幕」。
   - **安卓（Chrome）**：右上角菜单 → 「添加到主屏幕 / 安装应用」。
4. 从主屏幕图标打开，第一次用话筒和相机时允许权限；在设置页打开通知。

## 已知限制

- **语音转文字**用的是浏览器自带的识别：安卓 Chrome、iPhone Safari 支持，需要联网。不支持的浏览器仍会保存录音，可以用输入法键盘上的话筒补一句文字说明。
- **提醒**：网页应用在后台被系统关掉后，定时提醒可能不会弹出（尤其是 iPhone）。最可靠的是用「开始 → 做完了」流程；以后如果需要关掉应用也能准时提醒，需要加一个推送服务器。
- **数据只在本机**：清理浏览器数据会丢失记录，请定期「导出完整备份」。

## 开发

纯 HTML/CSS/JavaScript，没有构建步骤，也没有依赖。

```bash
python3 -m http.server 8000   # 打开 http://localhost:8000
npm test                      # 金额/类别识别的单元测试
```

| 文件 | 作用 |
| --- | --- |
| `index.html` / `styles.css` | 页面结构和样式 |
| `app.js` | 页面逻辑：首页事项计时、记一笔、账单、统计、提醒、设置 |
| `parser.js` | 从中文说明里识别金额和类别 |
| `voice.js` | 语音转文字 + 录音 |
| `db.js` | IndexedDB 本地存储（含照片、录音） |
| `sw.js` | 离线缓存、点击通知打开应用 |
