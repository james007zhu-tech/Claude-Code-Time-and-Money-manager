# 时间账本

时间管理和财富管理合在一起，主要靠**说一句话**来记录：

- 做了什么、用了多久、花了多少，一句话记下；
- 随时问「这几天我干什么去了」「这几年都干了些啥」「今年存了多少钱」，它会统计并朗读回答；
- 时间按**德鲁克**《卓有成效的管理者》的三步来管：记录 → 诊断 → 整合整块时间；
- 钱按**巴菲特**的常识来管：净资产、储蓄率、应急金、远离消费负债、复利、投资决策日记；
- 电脑（Mac / Windows）上有一个小程序自动记录每个软件用了多久，一起汇总分析。

手机上是一个网页应用（PWA），添加到主屏幕后像普通 App 一样用，能离线，数据只存在你自己的设备上。

## 怎么说

| 你说 | 它做什么 |
| --- | --- |
| 开始写季度方案，预计两小时 | 开始计时；两小时后提醒你「做完了吗」 |
| 做完了 / 做完了，打车花了28 | 结束计时并记下用时；没说花费会问你「花钱了吗？拍凭证 / 说花了多少 / 没花钱」 |
| 下午2点到4点和客户开会，打车来回60块 | 记一条：14:00–16:00，沟通会议，交通支出 ¥60 |
| 刷了一个小时抖音 | 记一条休闲时间（刚过去的一小时） |
| 午饭35块 / 二十八块五 / 三块五毛 | 记支出，自动识别金额和类别 |
| 工资到账1万5 | 记收入 ¥15000 |
| 招行卡余额5万3 / 基金市值12万 / 房贷还欠80万 / 信用卡欠了3500 | 更新账户余额，自动建账户、区分资产和负债 |
| 这几天我干什么去了？ / 上个月花了多少钱 / 这几年都干了些啥 | 跳到「回顾」，用文字和语音回答 |

说完后会提示「已记：…」，点「修改」可以补凭证照片、改类别；不想说话也可以直接打字。

### 多币种（人民币 / 泰铢 / 美元）

| 你说 | 记成 |
| --- | --- |
| 咖啡128元 / 35rmb / ¥35 | 人民币 |
| 按摩500泰铢 / 300铢 / 三百块泰铢 / ฿250 | 泰铢 |
| 酒店120美元 / 机票350刀 / $20 | 美元 |
| 午饭80块 / 花了200（没说币种） | 「默认币种」 |

- 默认币种在首页「说『块』= …」按钮上，点一下切换。人在泰国就切到泰铢，回国切回人民币。
- 每条记录保存原币金额；统计、净资产按汇率折算成一种「本位币」，并列出各币种的原始金额。汇率在 设置 → 币种与汇率 里手动填，或点「联网更新汇率」。
- 账户也可以设币种，例如「开泰银行余额5万泰铢」会建一个泰铢账户。

### 报销单（月底一键生成）与 ERP 对接

- 「财富」页的「待报销」里点「📄 生成报销单」，选范围（所有待报销 / 本月 / 上个月）、排版、报销币种、报销人和单位。
- **按科目分页**（默认）：
  - 第 1 页是汇总：报销人、单位、期间、各科目（交通费、住宿差旅费、餐饮费……）的笔数、凭证张数、金额、**在第几页**，合计和大写金额、签字栏；
  - 之后每个科目单独成页：先是这个科目的明细（日期、事项、付款方式、原币金额、报销金额、凭证号，缺凭证的标红「无」）和小计，接着是这个科目的凭证照片；凭证多就续页（「交通费（续）」）。
  - 每页底部有「第 x / y 页」，凭证号和明细序号对应。
- **一页汇总**：汇总 + 明细尽量一页，凭证另附粘贴页。
- 预览里可以「打印 / 存 PDF」、下载单据、导出 Excel 明细表、**导出给 ERP**（JSON + 带科目代码的分录 CSV），或在设置了推送地址后**直接推送到 ERP**。格式见 [docs/erp-export.md](docs/erp-export.md)。
- 在「设置 → 报销与 ERP 对接」里填员工编号、成本中心、各报销科目对应的 ERP 科目代码，以及推送地址和请求头。
- 交出去后点「标记为已提交」（推送成功会自动标记）；报销款到账时说「报销款到账 xxx」核销。
- 每月最后两天和下月头两天，如果还有没提交的待报销，会提醒你生成报销单。

### 账户（现金、泰铢卡、公司账户、微信、支付宝、人民币卡）

- 「财富」页点「添加常用账户」，一次建好：现金（泰铢）、个人泰铢卡、公司泰铢账户、微信、支付宝、人民币银行卡。名称、别名、币种、类型都可以改，也可以再加别的账户。
- 记账时在话里带上账户就行：「微信付了35块午饭」「打车60块用公司卡付的」「用现金买水果80」「支付宝买书58元」。没说账户时，用同币种里最近用过的个人账户；没说币种时（只说「块」），按账户的币种记。
- 拍凭证时会从付款方式认账户：微信支付 → 微信，支付宝 → 支付宝，现金 / เงินสด → 现金，PromptPay / K PLUS 等泰国银行 → 个人泰铢卡。
- 账户之间转钱也能说：「从支付宝转5000到微信」「从个人泰铢卡取了2000现金」「从人民币银行卡换了1万到个人泰铢卡，换成4万8泰铢」。手动记时选「转账」。转账不算收支。
- 余额：说「微信余额3000」或在账户里「核对余额」，之后的收支会自动加减，随时看到每个账户现在还有多少。
- **公司账户**单独统计：它的余额不算个人净资产，用它付的钱不算个人支出，也不用报销。

### 凭证识别

- 首页有「📷 拍凭证」「🖼️ 相册选凭证」两个按钮；记录编辑页最上面也可以拍照或从相册选（可多选）。
- 选好图片后会自动识别：**金额（实付总额）、币种、日期时间、商家、用途、类别**，填进还没手动改过的地方，请核对后保存。凭证上没写用途时，会按商家类型推断类别（例如 7-Eleven → 购物，Grab → 交通，酒店账单 → 旅行住宿）。
- 两种识别方式：
  - **开了 AI（设置里填 API Key）**：Claude 直接看图，中文、泰文、英文的小票、发票、微信/支付宝/银行付款截图、行程单都能读，最准。
  - **没开 AI**：在手机上做文字识别再按规则解析，免费。第一次使用要下载十几 MB 的识别模型（中文、英文、泰文），之后会缓存；速度较慢，拍得模糊时可能认不全。
- 泰国小票上的佛历年份（如 2569、69）会自动换成公历。
- 识别结果不对可以直接改，或点「🔍 重新识别」。

### 报销

- 在话里说清楚就行：「和客户吃饭1200泰铢，要报销」「打车60块公司出」「出差打车45美元可以报销」。这些会标成「待报销」；说「不报销」「自费」则不标。
- 要报销的钱是公司的，不算进你自己的支出；「财富」页有待报销清单，可以逐笔或全部标成已报销。
- 说「报销款到账3000」会记一笔报销款（不算收入），并提示「核销待报销」：从最早的开始，把金额对得上的几笔标成已报销。

## 五个页面

- **记录**：大话筒按钮、正在做的事（计时）、今天的时间和收支。
- **回顾**：按今天 / 这几天 / 本周 / 本月 / 今年 / 全部查看；一个月以内按天列出，更长的按月汇总（点某个月可以展开）；可以语音提问。
- **时间（德鲁克）**
  1. 记录：时间花在哪类事上（要事、沟通、杂务、学习、生活、通勤、休闲），以及电脑上各软件的时间；
  2. 诊断：最占时间的事逐项标「我来做 / 可委派 / 可不做」，算出每周能腾出多少小时；
  3. 整合：统计 90 分钟以上的整块专注时间、碎片时间，以及每天的专注时间。
- **财富（巴菲特）**：净资产及每月走势、本月储蓄率、财务体检（储蓄率 ≥20%、应急金 ≥6 个月、无消费负债、负债率）、账户列表、复利计算、投资决策日记（生意、能力圈、内在价值与安全边际、卖出条件）。只提供工具和公开的常识，不构成投资建议。
- **设置**：电脑记录同步、提醒、语音、AI、备份。

## 折叠屏（Galaxy Z Fold 等）

- **外屏**（窄）：单列，缩小间距和话筒，按钮和表格不会挤出屏幕。
- **内屏展开**：两栏。首页左边是话筒和正在做的事，右边是今天的记录；回顾、时间、财富、设置的卡片分两列排列；编辑弹层变宽，字段分两列。
- **半折叠·书本姿势**（铰链竖着）：两栏正好落在铰链左右，编辑弹层放在右半屏，不压在折痕上。
- **半折叠·笔记本姿势**（铰链横着）：首页上半屏看今天的记录，下半屏是话筒和输入框。

半折叠时的分屏用的是浏览器的 Viewport Segments 功能，需要较新的 Chrome / 三星浏览器；不支持时按普通两栏显示。

## 电脑端自动记录（Mac / Windows）

`agent/timeagent.py` 只用 Python 标准库。它每 5 秒看一眼当前窗口，合并成使用时段；超过 5 分钟没有键鼠操作就不计时。每天生成一个 `usage-<设备名>-<日期>.json`。

```bash
# Mac 自带 python3；Windows 先从 python.org 安装 Python 3
python3 timeagent.py install      # 设为开机自动运行（Mac 用 launchd，Windows 用启动文件夹）
python3 timeagent.py report       # 在终端里看最近 7 天的统计
python3 timeagent.py run --no-titles   # 前台运行；--no-titles 只记软件名，不记窗口标题
python3 timeagent.py uninstall
```

- 默认写到 iCloud Drive（Mac）或 OneDrive（Windows）里的 `TimeLedger` 文件夹；也可以用 `--out` 指定其他同步盘。
- Mac 第一次运行时需要在「系统设置 → 隐私与安全性 → 辅助功能 / 自动化」里允许 Python，才能读到窗口标题和浏览器域名。浏览器只记录域名，不记录完整网址。
- **在电脑浏览器里**打开时间账本：设置 → 选择同步文件夹，以后每次打开都会自动读取。
- **在手机上**：设置 → 导入记录文件，从「文件」App（iCloud Drive / OneDrive）里选择这些 JSON。
- 软件归到哪一类，可以在 设置 → 软件归类规则 里改。

手机和电脑之间互相同步记录：在一边「导出完整备份」，放到同步盘里，另一边导入（或放进电脑上选择的同步文件夹，会自动合并）。同一条记录不会重复。

## AI 理解（可选）

不开 AI 也能用，上面那些说法都由本地规则识别。在设置里填入你自己的 Anthropic API Key 后：

- 用 Claude 理解更随意的说法；
- 「这几年干了什么」这类问题，Claude 会按德鲁克和巴菲特的视角给出总结。

API Key 只保存在本机浏览器里，按用量付费。提问时会把相关记录发给 Anthropic。默认模型是 Claude Opus 5.5，也可以换成 Sonnet 5.5 或更便宜的 Haiku 5.5。

## 安装到手机

需要通过 HTTPS 打开（摄像头和麦克风的要求）。最简单的是 GitHub Pages：

1. 仓库 **Settings → Pages**，Source 选 “Deploy from a branch”，选分支和 `/ (root)`，保存。
2. 手机打开得到的网址：iPhone 用 Safari「分享 → 添加到主屏幕」；安卓用 Chrome 菜单里的「安装应用」。

## 已知限制

- **手机上各个 App 的使用时间无法自动读取**（网页应用拿不到系统的屏幕使用时间），手机上的时间靠说一句或「开始 / 做完了」来记。以后如果需要，可以做原生安卓 App，读取系统的使用统计。
- 语音转文字用的是浏览器自带的识别，需要联网；不支持的浏览器可以用输入法键盘上的话筒。
- 应用在后台被系统关掉后，定时提醒可能不会弹出（iPhone 尤其明显）。
- 数据只在本机，清理浏览器数据会丢失，请定期导出备份。

## 开发

纯 HTML/CSS/JavaScript，没有构建步骤。

```bash
python3 -m http.server 8000   # 打开 http://localhost:8000
npm test                      # 语音理解（JS）+ 电脑记录器（Python）的单元测试
```

| 文件 | 作用 |
| --- | --- |
| `app.js` | 首页、语音指令、开始/做完计时、提醒、启动 |
| `views.js` | 回顾、时间管理（德鲁克）、财富管理（巴菲特） |
| `sheet.js` | 记录编辑弹层、通用弹层 |
| `settings.js` | 设置、电脑记录同步、备份导入导出 |
| `parser.js` | 本地中文理解：金额、时长、时间段、余额、提问范围 |
| `analytics.js` | 时间与财务的统计计算、本地回答 |
| `ai.js` | 可选的 Claude 理解、问答和看凭证 |
| `report.js` | A4 报销单排版（按科目分页 / 一页汇总）、金额大写 |
| `erp.js` | 报销单导出给 ERP（JSON / CSV）和推送 |
| `accounts.js` | 账户模板、从话里和凭证上认出账户 |
| `receipt.js` | 凭证识别：本地文字识别 + 规则解析金额、日期、商家、类别 |
| `voice.js` | 语音转文字、录音、朗读 |
| `db.js` | IndexedDB 本地存储 |
| `agent/timeagent.py` | 电脑端使用时间记录器 |
